# Unbound Structure Blocks

plz let me save 1000x1000x1000 structure 🥺

## Usage
Very simple:
- If edited through **the UI**, structure blocks can have up to 256-block ranges and -128 or 127 block offsets.
- If edited through **other means** like `/data`, structure blocks should be granted infinite range.
- For the main functionality, this mod must be on the **server**. When installed on the **client**, it only increases the distance structure blocks' preview boxes can be seen from.

## Note
Although you *could* set a structure block to save a rediculously large object, this mod doesn't do any optimization so your server might freeze up.
